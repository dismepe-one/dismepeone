NO MAC
1. Extraia a pasta em Downloads.
2. Copie o .env que já funcionou na Fase 1:

   cp ~/Downloads/DISMEPE_ONE_2_0_REINICIO_LIMPO/.env \
      ~/Downloads/DISMEPE_ONE_2_0_FASE1B_HOMOLOGACAO/.env

3. Entre:
   cd ~/Downloads/DISMEPE_ONE_2_0_FASE1B_HOMOLOGACAO

4. Crie o ambiente:
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install --upgrade pip
   python -m pip install -r requirements.txt

5. Inicie:
   python -m uvicorn api.main:app --host 127.0.0.1 --port 8000

6. Abra:
   http://127.0.0.1:8000/health

   Esperado:
   ok=true
   version=2.0.0-phase1b

7. Abra:
   http://127.0.0.1:8000/
